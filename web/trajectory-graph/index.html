Interaction guide

Read the graph at full speed

  1. 1
    Choose a task

    Click any task in the left rail to load its stored witness graph.

  2. 2
    Trace a state

    Click a node to highlight its shortest rendered path from a root and inspect every step.

  3. 3
    Inspect a transition

    Click an edge to see every function that maps between those two states.

  4. 4
    Move naturally

    Wheel or pinch to zoom, drag the background to pan, and drag any node to make space.

  5. 5
    Expand safely

    Choose Expand, set a function palette and budget, then build a palette-relative certified neighborhood.

  6. 6
    Chain candidates

    Inspect a reached state or use it as the next root; compatible functions refresh for its type.
